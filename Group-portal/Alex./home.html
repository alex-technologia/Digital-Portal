Overview of operating systems

An operating system (OS) is foundational system software that manages computer hardware and coordinates software resources, serving as an intermediary between user applications and physical components like the CPU, memory, and storage. At its core lies the kernel, which handles essential tasks such as process scheduling, virtual memory allocation, file systems, device communication via drivers, and security isolation between user and system privileges. Popular operating systems include general-purpose systems like Linux, Windows, and macOS, mobile platforms such as Android and iOS, and deterministic real-time systems (RTOS) used in embedded devices.
