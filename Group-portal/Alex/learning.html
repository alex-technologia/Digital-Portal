Lifelong Learning in Operating System

Operating systems continues to be developed to suits the peoples usage and finding ways to combine with new technologies such as AI. Because of this people need to continue learning about operating system and develop their skills.

Independent Learning During the Project

While completing this project, I independently researched low-level system mechanics that go beyond basic user-interface interaction. Specifically, I explored how kernel modules manage hardware resource abstraction, how CPU scheduling algorithms (such as Round Robin and Multilevel Feedback Queues) balance task priority, and how virtual memory prevents application crashes through page swapping.

2. Why the Selected Topic is Important

Operating systems are the foundational bridge connecting software applications to physical hardware. Understanding operating system principles is essential because every modern computing system—from mobile phones and personal computers to cloud servers and embedded IoT devices—relies on an operating system to provide security, stability, process isolation, and efficient resource allocation.

3. New Knowledge and Skills Acquired

Through this project, I gained a core understanding of system architecture, including the distinction between kernel space and user space, system calls, and how operating systems balance multi-tasking processes. In addition, I acquired practical command-line and system administration skills, learning to use terminal tools to monitor real-time resource utilization, inspect active processes, and write basic scripts for process management.

4. Skills or Knowledge to Develop Further

In the future, I want to deepen my technical expertise in low-level kernel development and system programming using languages like C or Rust. I also aim to broaden my knowledge of cybersecurity mechanisms within operating systems, such as memory protection and access control, as well as modern virtualized and containerized environments used in cloud computing.

5. How I Plan to Continue Learning

To continue learning about operating systems, I plan to work on hands-on technical labs, such as building customized Linux systems and setting up virtual machine environments for testing. I also intend to follow open-source system projects, complete open-access university coursework on kernel internals, and read research publications from systems engineering organizations.

6. Reflection on Independent Learning Experience

Independent learning throughout this project transformed my perspective on computer hardware and software integration. Moving past high-level abstractions forced me to troubleshoot complex errors self-sufficiently using technical documentation and developer resources. This experience reinforced that mastering technology requires a mindset of active, continuous inquiry rather than static memorization.

Coursera: Google IT Support Professional Specialization

Google’s course, Operating Systems and You: Becoming a Power User, is a foundational lifelong learning resource. It provides an excellent entry point into navigating, configuring, and troubleshooting both Windows and Linux file systems, user permissions, and process management.

Google IT Support Professional Specialization

OSTEP: "Operating Systems: Three Easy Pieces"

OSTEP is a free online textbook that provides a comprehensive introduction to operating system concepts. It covers topics such as process management, memory management, and file systems, with a focus on practical applications and real-world examples.

OSTEP: Operating Systems: Three Easy Pieces

MIT OpenCourseWare: Operating System Engineering

MIT’s course on Operating System Engineering provides in-depth lectures and assignments that explore the design and implementation of operating systems. It covers advanced topics such as concurrency, scheduling, and file systems, making it a valuable resource for those looking to deepen their understanding of OS internals.

MIT OpenCourseWare: Operating System Engineering

edX: Introduction to Operating Systems

This course from the University of California, San Diego, provides a comprehensive overview of operating system principles and design. It covers essential topics such as process management, memory management, and file systems, with a focus on real-world applications.

edX: Introduction to Operating Systems

Cisco Networking Academy: Operating Systems Concepts

Cisco’s Networking Academy offers a course on operating system concepts that covers the fundamentals of OS architecture, process management, and file systems. It provides hands-on labs and practical exercises to reinforce learning.

Cisco Networking Academy: Operating Systems Concepts
