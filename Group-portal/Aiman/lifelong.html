Lifelong Learning

What I Learned

While building this project, I discovered the difference between utility software and applications. Utility software provides for performing tasks as a system administrator. In contrast, application software provides for performing tasks as an end user.

Why Utility Programs Are Important

Utility programs are essential for keeping computer systems secure, and fast. Without them, computers would become vulnerable to viruses and lack proper data backups in case of a crash.

New Knowledge and Skills Acquired

  • Understanding how IT staff use disk cloning to set up multiple computers quickly.
  • Learning how encryption and backup utilities protect sensitive data in fields like healthcare and business.
  • Organizing and designing structured web content.

Skills and Knowledge I Want to Develop Further

  • More in-depth HTML and CSS knowledge.
  • Hands-on experience using advanced command-line tools and diagnostic software
  • Understanding how to use and manage utility programs effectively.

Future Learning Plans

I plan to take IT support and system administration courses on platforms like Coursera and Cisco Networking Academy.

Reflection

Building this project was a valuable learning experience. I learned how to build and design structured web content, which will be useful for future projects.

Credible Lifelong Learning Resources

Microsoft Learn & Sysinternals

  • Advanced Windows troubleshooting tools and system monitoring.
  • Provides official technical documentation and professional tools used by IT experts.
  • Allows learners to move from basic software concepts to real-world technical troubleshooting

Coursera (Google IT Support Professional Certificate)

  • Operating systems, computer hardware, and routine maintenance.
  • Features video lessons and practical labs created by industry professionals.
  • Connects theory with industry-ready problem-solving skills.

Cisco Networking Academy (NetAcad)

  • Computer hardware basics, troubleshooting, and network security.
  • Offers structured, self-paced modules with interactive lessons.
  • Builds a strong foundation in hardware and networking.

TutorialsPoint

  • Clear definitions of system software and utility types (like antivirus and backup tools).
  • Provides concise, easy-to-read guides for quick reference.
  • Serves as a handy reference handbook for studying operating system concepts.

Class Central

  • A directory of online courses and tutorials for PC maintenance.
  • Filters and reviews courses from multiple platforms based on student feedback.
  • Helps find specialized courses as technical interests grow.
