Independent Learning Reflection

While completing this project, I learned more about cybersecurity and how it is used to protect computers, networks, accounts, and information. I also learned how to research information from different sources and organise it into a website using HTML and CSS.

Before working on this project, I mainly understood cybersecurity as protecting computers from viruses and hackers. After doing more research, I learned that cybersecurity also includes protecting personal information, preventing unauthorised access, securing networks, and helping organisations continue their work safely.

Why Cybersecurity Is Important

Cybersecurity is important because people and organisations depend on digital systems every day. Cyber attacks can result in stolen information, financial losses, damaged systems, and privacy problems. Good cybersecurity practices can reduce these risks and help people use technology more safely.

New Skills and Knowledge I Developed

  • Improved my understanding of common cybersecurity threats.
  • Learned about the CIA Triad: Confidentiality, Integrity, and Availability.
  • Learned how cybersecurity is used in workplaces and organisations.
  • Improved my HTML and CSS skills by developing this website.
  • Improved my ability to research and organise information from different sources.

Skills I Would Like to Develop Further

There are still many areas of cybersecurity that I would like to learn more about. In particular, I would like to improve my knowledge of computer networking, ethical hacking, penetration testing, Linux, and security tools. I would also like to gain more practical experience instead of only learning the theory.

My Future Learning Plan

I plan to continue learning about cybersecurity by using online courses and hands-on practice platforms. I would like to grind out leetcode problems to improve my programming skills, which are essential for cybersecurity. In the future, I also hope to work towards recognised cybersecurity certifications that can support my studies and career.

My Reflection

This project showed me that cybersecurity is a subject that requires continuous learning because technology and cyber threats are always changing. Independent learning allowed me to research topics at my own pace and choose information that was useful for the project. Some topics were difficult to understand at first, but researching them and comparing different sources helped me understand them better. Overall, the project increased my interest in cybersecurity and encouraged me to continue learning about it in the future.

Recommended Lifelong Learning Resources

The following resources can be used to continue learning about cybersecurity after completing this project. They provide a mixture of beginner courses, practical exercises, and more advanced cybersecurity training.

Platform Name What Can Be Learned Why It Is Useful Future Learning Support
TryHackMe Cybersecurity fundamentals, networking, Linux, penetration testing, and defensive security. Provides hands-on labs that allow learners to practise cybersecurity skills in a safe environment. Can help build practical skills before moving on to more advanced cybersecurity topics.
Cybrary Cybersecurity, networking, cloud security, and other information technology topics. Provides structured courses that can be studied at the learner's own pace. Can be used to continue learning and prepare for future cybersecurity certifications.
Coursera - Google Cybersecurity Cybersecurity fundamentals, Python, Linux, SQL, and security tools. Provides a structured beginner-friendly learning path covering several important cybersecurity skills. Can help build a foundation for further cybersecurity studies and future career development.
SANS Cyber Aces Basic concepts in operating systems, networking, and system administration. Helps learners understand important technical foundations used in cybersecurity. Provides a strong foundation before studying more advanced cybersecurity subjects.
Hack The Box Ethical hacking, penetration testing, vulnerability assessment, and security challenges. Uses practical challenges to help learners apply cybersecurity knowledge to realistic situations. Can provide continued practice and help develop problem-solving skills for future cybersecurity roles.
